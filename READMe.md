USING NMAP(ZENMAP) TO PERFORM A NETWORK RECOINASSANCE

Step 1: Type the website address on the target field

Step 2: Performing a slow but comprehensive scan select Intense scan from the profile drop down

Step 3: Click scan

Step 4: Select ports/host tab to display target system interesting ports

Step 5: Select topology tab to view interactive map of the network path from my computer to the target host

Step 6: Select host details to view the host ipv4 address.
